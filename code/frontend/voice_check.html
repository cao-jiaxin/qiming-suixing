这三种结果分别意味着什么

提示音和中文都听得到
这台手机的语音是好的。那问题多半在主页面：回到主页面后，要先用手指点一下屏幕（启动闸门），页面才会有声音。
提示音听得到，中文听不到
音量和扬声器没问题，缺的是系统里的中文语音。做法：设置 → 无障碍 → 文字转语音，确认已安装语音引擎、语言选中文；装不上就换 Chrome 或 Safari 打开。
两个都听不到
先别怀疑软件：① 按侧面音量键把媒体音量调起来（不是铃声音量）；② 关掉静音和勿扰；③ 断开蓝牙耳机——连着耳机时声音会走到耳机里，自己听不到。
